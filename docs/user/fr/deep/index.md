Cette partie suppose que Meshloom tourne déjà. Elle reprend ce qui vivait dans les README avancés du dépôt, sans vous demander de les ouvrir pour un réglage.

Le vocabulaire du projet est employé ici sans détour, mais toujours nommé au passage : transport, fanout, flood scope, path hash mode, secure context. Si un terme est encore flou, la première partie de la documentation le pose en clair : [Qu’est-ce que c’est](/docs/what/) et [Autour des messages](/docs/around/).

Deux pages valent une lecture avant les autres. [Variables et réglages](/docs/deep/environment/) sépare ce qui se décide au démarrage de ce qui vit dans la base. [Meshloom Community](/docs/deep/community/) est activé sur une install neuve sauf opt-out. [Sécurité](/docs/deep/security/) dit ce que Meshloom ne protège pas.
