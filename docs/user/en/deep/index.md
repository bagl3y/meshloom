This section assumes Meshloom is already running. It takes what used to live in the advanced READMEs so you do not have to open the repo for a setting.

Project terms appear directly: transport, fanout, flood scope, path hash mode, and secure context. If one is unclear, start with [What is it](/en/docs/what/) and [Around messages](/en/docs/around/).

Read [Variables and settings](/en/docs/deep/environment/) first to separate startup configuration from database-backed settings. [Meshloom Community](/en/docs/deep/community/) is on for new installs unless you opt out. [Security](/en/docs/deep/security/) explains what Meshloom does not protect.
